# AI Dream Visualization ✨

An AI-powered application that converts a user's dream description into a cinematic video.

## Features

- AI-based dream visualization
- Text-to-image generation using Stable Diffusion
- Keyframe generation
- Smooth frame animation
- MP4 video generation
- Streamlit web interface
- Video preview and download

## Technologies Used

- Python
- Stable Diffusion
- PyTorch
- Diffusers
- OpenCV
- NumPy
- MoviePy
- Streamlit

## How It Works

1. User enters a dream description.
2. AI generates dream scene keyframes.
3. Keyframes are converted into animation frames.
4. Frames are combined into an MP4 video.
5. The generated video is displayed in the Streamlit interface.
